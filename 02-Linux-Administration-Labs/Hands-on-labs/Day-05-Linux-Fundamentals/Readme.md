# Day 5 – Linux File System Navigation & File Management

## Overview

Today's lab focused on learning the fundamentals of navigating and managing the Linux file system from an Amazon EC2 instance. I connected to a Linux server using SSH, explored the directory structure, and practiced essential Linux commands used for navigation and file management. These are core skills required for troubleshooting and administering Linux-based servers in AWS.

---

# Objectives

* Connect to an Amazon EC2 Linux instance using SSH.
* Navigate the Linux file system.
* Explore directories and view file information.
* Create, move, copy, rename, and delete files and directories.
* Edit and view file contents using basic Linux utilities.

---

# Hands-on Tasks

## Task 1 – Connect to the Linux Server

### Objective

Establish a secure SSH connection to an Amazon EC2 Linux instance.

### What I Did

* Connected to my Amazon EC2 instance using SSH.
* Verified that I had successfully logged into the Linux server.
* Confirmed I was ready to execute Linux commands.

### Result

I successfully established a remote connection to the Linux server.

---

## Task 2 – Navigate the Linux File System

### Objective

Become familiar with navigating directories and inspecting files from the command line.

### What I Did

I practiced several Linux navigation commands, including:

* `pwd` to display the current working directory.
* `ls` to list directory contents.
* `ls -l` to view detailed file information.
* `ls -la` to display all files, including hidden files.
* `cd` to move between directories.
* `tree` to view the directory structure in a hierarchical format.

### Result

I became comfortable navigating the Linux file system and locating files and directories using common command-line tools.

---

## Task 3 – Create and Manage Files

### Objective

Practice common Linux commands used for creating and managing files and directories.

### What I Did

I worked with several file management commands, including:

* `mkdir` to create directories.
* `rmdir` to remove empty directories.
* `touch` to create new files.
* `nano` to create and edit text files.
* `cat` to display file contents.
* `cp` to copy files.
* `mv` to move and rename files.

### Result

I successfully created, edited, copied, moved, renamed, and removed files and directories while gaining confidence with basic Linux file management.

---

# Key Takeaways

* SSH provides secure remote access to Linux servers hosted on Amazon EC2.
* Understanding the Linux directory structure is essential for system administration and troubleshooting.
* Navigation commands help locate files and directories efficiently.
* File management commands are fundamental skills for managing Linux servers.
* Knowing the difference between copying, moving, creating, and deleting files helps prevent accidental mistakes during administration.
