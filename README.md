# AWS Cloud Support Labs

## About This Repository

Welcome to my AWS Cloud Support Labs repository.

This repository documents my hands-on journey to becoming an AWS Cloud Support Engineer through a structured 60-day learning roadmap.

The goal is to build practical experience by completing real AWS labs, troubleshooting production-like scenarios, documenting solutions, and creating enterprise-style projects.

Every lab in this repository includes:
- Hands-on implementation
- Troubleshooting exercises
- Commands used
- Screenshots
- Lessons learned
- Professional documentation
